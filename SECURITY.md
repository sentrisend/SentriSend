# Security policy

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/sentrisend/SentriSend/security/advisories/new) (in the repository, choose **Security → Report a vulnerability**). If you cannot use GitHub's private reporting, email security@sentrisend.com.

Include what you found, steps to reproduce, and the potential impact. Use test accounts and synthetic data; do not include real customer data.

Please do not open a public issue for a security problem. Do not test against other people's accounts or send spam through SentriSend.

This repository contains documentation and examples only, so reports about the hosted SentriSend service are the main scope.
